# Бот игры «Киллер» — Railway + PostgreSQL

## Состав проекта

| Файл | Назначение |
|---|---|
| `bot.py` | вся логика бота, обработчики, админка, фоновые задачи |
| `db.py` | слой PostgreSQL на psycopg2: пул соединений, схема, миграции, настройки |
| `keyboards.py` | подписи кнопок и все клавиатуры |
| `test_flow.py` | локальный тест игровой логики (без PostgreSQL) |
| `requirements.txt`, `Procfile`, `runtime.txt` | файлы для Railway |

## Что сделано по пунктам

**1. Кнопки без слэшей.** Клавиатура во время игры: «🎯 Моя цель», «🔫 Убить жертву», «👤 Моё досье», «📊 Статистика», «✉️ Письмо киллеру», «✉️ Письмо жертве», «💰 Письмо игроку (1 очко)», «🏆 Топ киллеров», «📖 Правила», «❓ Помощь». Кладбище из меню игроков убрано (см. ниже). Все кнопки ловятся через `MessageHandler(filters.Regex(...))`, слэш-команды оставлены дублёрами. Клавиатура сама подстраивается под состояние: гость → лобби → игра → выбывший.

**2. Полный переход на psycopg2.** `sqlite3` убран, всё в `db.py`: `ThreadedConnectionPool`, `RealDictCursor` (поля по имени), плейсхолдеры `%s`, `BIGINT / SERIAL / TIMESTAMPTZ / BOOLEAN`, `ON CONFLICT ... DO UPDATE` вместо `INSERT OR REPLACE`, `ILIKE` для поиска по имени. При старте выполняются `CREATE TABLE IF NOT EXISTS` и мягкие миграции `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`, так что новые поля появятся и на уже существующей базе.

**3. Досье для админа + замена фото.** `/view_profile <id | @username | часть имени>` присылает два сообщения: фотографию с досье в том виде, в каком его видит охотник («👁 ТАК ЭТО ВИДИТ ОХОТНИК»), и полную техническую карточку — все поля, личный код, кто на него охотится, его цели, дата регистрации и смерти, последнее слово. Если фото нет или битое — об этом прямо написано. `/set_photo <id>` показывает текущее фото и ждёт новое (фото, картинку-файл или `file_id`), сохраняет его в базу, сразу показывает предпросмотр и уведомляет игрока.

**4. Отмена регистрации.** В меню зарегистрированного участника до старта игры остаётся кнопка «🚫 Отменить регистрацию». Есть подтверждение («Да, удалить мою анкету» / «Нет, я остаюсь в игре»), анкета и связи с целями удаляются, организаторам уходит уведомление. После старта игры кнопка отвечает, что выйти самостоятельно нельзя.

## Новые фишки (пункт 5)

Реализовано в коде:

- **Очки вместо простого счёта убийств.** У каждого игрока своя «цена головы» (`reward`). Убил дорогую цель — получил больше очков. Очки теперь ещё и валюта для платных писем (см. ниже). Админ ставит цену через `/set_reward_player`, базовую — через `/set_global_reward`.
- **Кладбище скрыто от игроков.** Кнопка «🪦 Кладбище» убрана из игрового и выбывшего меню — участники не должны знать, кто уже устранён. Команда `/graveyard` и сама функция остались, но доступны только админам (`ADMIN_IDS`) — игроку без прав бот ответит «эта информация недоступна во время игры».
- **Килл-фид только админам.** Старая рассылка «💀 Ещё один выбыл» всем живым убрана: обычные игроки теперь не видят, кто выбыл — только сама жертва получает личное уведомление о своей «смерти». Каждое убийство сразу уходит всем админам с деталями (кто, кого, сколько осталось живых), `/killfeed on|off` управляет только дублирующим админ-сводками, админы всё равно получают уведомления.
- **🏆 Топ киллеров** вместо «топ игроков». Сортировка по числу убийств (`kills DESC`), при равенстве — по сумме убийств самих его жертв (`victims_kills_sum DESC`), далее — по времени последнего убийства: кто раньше от начала игры совершил последнее убийство — тем выше (`last_kill_date ASC`). Зашито в одном SQL-запросе `TOP_KILLERS_SQL` и используется как для `/top`, так и для итоговой таблицы по завершении игры.
- **💰 Платные письма любому игроку за очки.** Кнопка «💰 Письмо игроку (1 очко)»: выбираешь живого получателя из нумерованного списка (вводишь номер или имя), выбираешь подпись — «🔫 От киллера» или «💀 От жертвы» (письмо всегда анонимно для получателя, видна только выбранная роль), пишешь текст — с баланса списывается 1 очко (`MSG_ANY_PRICE`). Графики в платных письмах не пересылаются (только текст). Если очков не хватает — бот ответит «❌ Не хватает средств» и ничего не спишет. Письма своему киллеру/своей жертве (кнопки «✉️ Письмо киллеру/жертве») остаются бесплатными и могут содержать фото, как и раньше.
- **Админ видит всё.** Абсолютно любое письмо (бесплатное киллеру/жертве или платное любому игроку) дублируется всем админам сразу в боте, НЕанонимно — с реальными именами и ID отправителя и получателя, текстом/фото, названным отправителем стилем (от киллера/жертвы) и суммой списания, если письмо платное. Цель — чтобы организаторы могли модерировать переписку и разбирать споры, не теряя анонимности для самих игроков.
- **Последнее слово.** Выбывший может оставить фразу, она появляется на кладбище (видно только организаторам).
- **Анонимные записки** охотнику и жертве теперь через кнопку и диалог (не `/msg_target текст`), с сохранением в таблице `anon_messages` — организатор может разбирать спорные ситуации.
- **Подсказки от организаторов.** `/add_hint <id> <текст>` — подсказка появляется в досье цели и сразу прилетает охотнику. Удобно, если охота встала.
- **Особо опасен** — метка и причина, видна в досье.
- **Армагеддон** — каждому живому вторая цель, когда игра затухает.
- **Автозавершение по таймеру** — фоновая задача проверяет срок каждые 30 минут, за сутки до финала присылает предупреждение, по истечении срока сама рассылает итоги.
- **Ежедневная сводка** живым: убийств за сутки, сколько осталось, кто лидирует (по числу убийств).
- **Самовосстановление цепочки.** Если цель выбыла, была удалена или охотник остался без жертвы — новая цель назначается автоматически (сначала из «свободных», на кого никто не охотится), охотник получает уведомление (без имени выбывшего).
- **Проверка взаимных охот** `/check_pairs` + ручное `/reassign <hunter_id> <target_id>`.
- **Возврат в игру** `/revive <id>` — на случай спорного убийства.
- **Экспорт** `/export` — CSV со всеми участниками (открывается в Excel, разделитель `;`).
- **Контроль качества анкет:** `/list_players` помечает 📵 тех, у кого нет фото; `/start_game` предупреждает о таких игроках до старта; `/status` показывает живых без цели.
- Защита от подбора кода: 5 неверных попыток — стоп и сигнал организаторам.

Идеи на будущее (не в коде, чтобы не усложнять первый запуск): «контракты» на конкретного игрока с повышенной наградой, зоны безопасности (столовая, библиотека), режим «последний час» с двойными очками, магазин на очки (купить подсказку/сменить цель), командный режим факультет против факультета, фотоподтверждение убийства с проверкой организатором.

## Деплой на Railway

1. **Проект и база.** В Railway: `New Project` → `Deploy from GitHub repo` (залейте эти файлы в репозиторий) → затем `New` → `Database` → `Add PostgreSQL`.
2. **Переменные окружения** сервиса бота (`Variables`):
   - `BOT_TOKEN` — токен от @BotFather;
   - `ADMIN_IDS` — ваш Telegram ID, можно несколько через запятую: `1513781380,987654321`;
   - `DATABASE_URL` — значение `${{Postgres.DATABASE_URL}}` (Railway подставит сам через Reference).
3. **Тип сервиса.** Бот работает через long polling, веб-порт не нужен. `Procfile` уже задаёт `worker: python bot.py`; если Railway всё же спросит Start Command — укажите `python bot.py`.
4. **Один экземпляр.** Держите Replicas = 1: два процесса с одним токеном получат конфликт polling.
5. Схема таблиц создаётся автоматически при первом запуске, отдельных миграций запускать не нужно.

Токен из старого файла лучше отозвать в @BotFather: он попал в исходники в открытом виде. В новой версии токен читается только из переменной окружения, значения по умолчанию нет.

Локальный запуск:

```bash
pip install -r requirements.txt
export BOT_TOKEN=... ADMIN_IDS=... DATABASE_URL=postgresql://user:pass@localhost:5432/killer
python bot.py
```

Проверка игровой логики без базы: `python test_flow.py`.

## Команды организатора

`/admin` выводит всю панель. Основное:

- игра: `/start_game`, `/end_game`, `/reset_game CONFIRM`, `/set_time <дни>`, `/open_reg`, `/close_reg`, `/killfeed on|off`, `/status`
- игроки: `/list_players`, `/view_profile <id>`, `/set_photo <id>`, `/edit_player <id> <поле> <значение>`, `/add_hint <id> <текст>`, `/set_reward_player <id> <очки>`, `/set_global_reward <очки>`, `/set_danger <id> <причина>`, `/remove_danger <id>`, `/add_player`, `/remove_player`, `/revive <id>`
- охота: `/show_targets`, `/reassign <hunter_id> <target_id>`, `/check_pairs`, `/armageddon`, `/broadcast <текст>`, `/export`
- только админам: `/graveyard` — полный список выбывших с последними словами (игрокам эта информация не показывается); все письма игроков (бесплатные и платные) автоматически дублируются всем админам в боте с реальными именами
